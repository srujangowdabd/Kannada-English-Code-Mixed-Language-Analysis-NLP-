# Kannada-English Code-Mixed Language Analysis (NLP)

## Overview
This project focuses on analyzing Kannada-English code-mixed text using Natural Language Processing (NLP) techniques. It uses the DravidianCodeMix dataset to explore multilingual text patterns and language classification.

## Objectives
- Analyze Kannada-English code-mixed text.
- Perform text preprocessing and cleaning.
- Explore linguistic patterns in multilingual data.
- Apply NLP techniques for text analysis and classification.

## Technologies Used
- Python
- Pandas
- NumPy
- Natural Language Processing (NLP)
- Google Colab
- Scikit-learn

## Dataset
DravidianCodeMix Dataset – A collection of code-mixed text containing multiple Dravidian languages and English.
